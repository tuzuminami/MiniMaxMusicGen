# 🎵 ローカル音楽生成アプリ

**あなたの Mac の中だけ** で音楽をつくるアプリです。
歌詞もプロンプトも、つくった曲も、**インターネットには一切送りません**。

- 完全無料（月額・従量課金なし）
- API キー不要
- クラウド不要。セットアップが終わればオフラインで使えます
- 日本語の歌詞を歌わせられます

内部では [MiniMax-Music3](https://huggingface.co/MiniMaxAI/MiniMax-Music3) を
Apple 純正の [MLX](https://github.com/ml-explore/mlx) で動かしています。

---

## 1. このアプリについて

| | |
|---|---|
| 対象 | Apple Silicon の Mac（M1/M2/M3/M4）、メモリ 16GB 以上 |
| 動作確認 | MacBook Pro M3 Pro / メモリ 18GB / macOS 26 |
| 使うモデル | MiniMax Music 3（4bit 量子化・約 9GB） |
| 出力 | WAV ファイル（44.1kHz ステレオ） |
| 必要なディスク | 約 15GB（モデル 9GB ＋ 作業領域） |

**Windows・Intel Mac では動きません。** Apple Silicon 専用です。

---

## 2. 初回セットアップ

### かんたんな方法

1. このフォルダの中の **`start.command` をダブルクリック** します。
2. 「開発元が未確認」と出た場合は、`start.command` を **右クリック → 開く** を選び、
   確認ダイアログで「開く」を押してください（初回のみ）。
3. 自動でセットアップが始まります。終わるまで待ちます。
4. 途中で「モデルをダウンロードしますか？」と聞かれたら `y` を押します（約9GB）。

### うまくいかないとき（ターミナルを使う方法）

```bash
cd <このフォルダ>
bash scripts/setup.sh      # Python環境とライブラリの準備
./bin/local-music download # モデルの取得（約9GB）
./bin/local-music doctor   # 環境の確認
```

`uv` が入っていないと言われたら、先に次を実行してください。

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

> セットアップ中にインターネットを使うのは、**ライブラリとモデルの取得だけ**です。
> それ以外の場面で外部と通信することはありません。

---

## 3. 起動方法

**`start.command` をダブルクリック** するだけです。

ブラウザが自動で開き、次の画面が表示されます。

```
http://127.0.0.1:7860
```

このアドレスは**あなたの Mac の中だけ**のものです。外部からは接続できません。

終了するときは、開いているターミナルのウィンドウで **Control + C** を押します。

---

## 4. 曲をつくる

「🎵 曲をつくる」タブで、上から順に入力します。

1. **どんな曲にしたいですか？** — 日本語でOK。例:
   ```
   夏の夕方をイメージした少し切ないピアノポップ。
   テンポは遅め。女性ボーカル。
   映画のエンディングのような雰囲気。
   ```
2. **歌詞** — 空のままなら歌なしの曲になります
3. **ボーカル** — 女性／男性／インストゥルメンタル／自動
4. **ジャンル**
5. **雰囲気** — いくつでも選べます
6. **テンポ**
7. **長さ** — **はじめは 30 秒がおすすめ**です
8. **動作モード** — 迷ったら `Low Memory`

> **「長さ」は上限です**
> 指定した秒数は「ここまで」という上限で、ぴったりその長さになるわけではありません。
> 曲が自然に終わると短くなります（例: 上限60秒 → 実際21秒）。
> 長い曲がほしいときは、**歌詞を多めに書く**と長くなりやすいです。

最後に **「🎶 この内容で作曲する」** を押します。

生成中は「いま何をしているか」が右側に表示されます。
できあがると、その場で再生できます。

> **どれくらい時間がかかる？**
> 30秒の曲で数分かかります。長い曲ほど時間もメモリも必要です。
> 途中でやめたいときは「⏹ 停止」を押してください。

---

## 5. 日本語の歌詞

歌詞欄にそのまま日本語を入力してください。変換や設定は不要です。

**空行で区切る**と、自動で「Aメロ・サビ」などの構成をつけます。

```
風がとおる 白い午後
遠くで揺れる夏の音

まだ名前のない気持ちを
そっと空へ放した
```

自分で構成を指定したい場合は、`[verse]` `[chorus]` `[bridge]` などを行頭に書きます。

---

## 6. インスト曲（歌なし）

次のどちらかにすれば、歌のない曲になります。

- **ボーカル** で「インストゥルメンタル」を選ぶ
- **歌詞を空のままにする**（ボーカルが「自動」のとき）

このとき、ジャンルに合わせて主旋律を担当する楽器（ピアノ、ギターなど）が
自動で指定されます。

---

## 7. 動作モード（プリセット）

| モード | 使うモデル | 向いている場面 |
|---|---|---|
| **Low Memory** | 4bit | いちばん安全。メモリが少ないとき。**まずはこれ** |
| **Balanced** | 4bit | ふだん使い。品質と速さのバランス |
| **Quality** | 6bit | 高品質だが重い。18GB では他アプリを閉じてから |

> 18GB の Mac では **Low Memory / Balanced** をおすすめします。
> 8bit モデルは 18GB では動作が不安定なため、標準では使いません。

---

## 8. Seed（同じ曲をもう一度つくる）

「詳細設定」の **Seed** に同じ数字を入れると、同じ入力から**ほぼ同じ曲**が出ます。

- `-1` … 毎回ちがう曲（ランダム）
- 好きな数字 … 同じ曲を再現できる

気に入った曲の Seed は、履歴と `metadata.json` に記録されています。

---

## 9. 履歴

「📁 履歴」タブに、つくった曲の一覧が出ます。

行をクリックすると再生できます。「📂 フォルダを開く」で Finder が開きます。
削除は確認のうえ実行されます。

---

## 10. 保存場所

曲は次の形で保存されます。

```
outputs/
└── 2026-08-17_014530_曲名/
    ├── song.wav          ← 音源（これが本体・高音質）
    ├── song.mp3          ← 共有しやすい形式（ffmpeg があるとき）
    ├── metadata.json     ← 設定の記録（Seed など）
    ├── prompt.txt        ← 実際に使われたプロンプト
    ├── lyrics.txt        ← 歌詞
    └── generation.log    ← 生成の記録
```

WAV ファイルは、そのまま GarageBand や iMovie で使えます。
MP3 は ffmpeg を使ってお使いの Mac の中で変換しています（外部サービスは使いません）。

---

## 11. モデル

「📦 モデル管理」タブで、モデルの状態を確認・操作できます。

| ボタン | 動作 |
|---|---|
| ⬇️ ダウンロード | モデルを取得（必要なファイルだけ） |
| 🔍 確認 | ファイルが揃っているかチェック |
| 🗑 削除 | 確認のうえ削除（ディスクを空けたいとき） |
| 📂 フォルダを開く | 保存先を Finder で開く |

モデルは `models/` に保存されます。Git には含まれません。

---

## 12. 完全オフラインで使う

モデルのダウンロードが終われば、**Wi-Fi を切っても動きます**。

確認したい場合:

```bash
# Wi-Fi を切ってから
.venv/bin/python scripts/smoke_test.py --offline
```

アプリは生成時に `HF_HUB_OFFLINE=1` を設定し、外部へ問い合わせません。
テレメトリ（利用状況の送信）もすべて無効化しています。

---

## 13. メモリが足りないとき

生成前に自動でメモリを確認し、足りなければ警告します。

**対処法（効果の大きい順）**

1. **Chrome / Safari のタブを閉じる**（いちばん効きます）
2. Photoshop、Docker、他の AI アプリを終了する
3. **曲の長さを 30 秒にする**
4. 動作モードを **Low Memory** にする
5. Mac を再起動する（スワップが溜まっているとき）

警告画面の「🔽 Low Memory に変更して生成する」を押すと、軽い設定で作り直します。

---

## 14. アップデート

```bash
uv pip install -U "mlx-audio @ git+https://github.com/Blaizzy/mlx-audio.git@main"
./bin/local-music doctor
```

---

## 15. 困ったときは

| 症状 | 対処 |
|---|---|
| `start.command` が開けない | 右クリック → 開く → 「開く」を押す |
| 「モデルがありません」と出る | 「📦 モデル管理」でダウンロード |
| 生成が途中で止まる | メモリ不足の可能性。上の **13.** を試す |
| ブラウザが開かない | 手動で `http://127.0.0.1:7860` を開く |
| ポートが使用中 | `config/settings.json` の `port` を変更 |
| とにかく状態を知りたい | `./bin/local-music doctor` |

診断は「🩺 システムチェック」タブからも実行できます。

---

## 16. アンインストール

このフォルダごとゴミ箱に入れれば完了です。
システムには何もインストールしていません（`sudo` は一度も使いません）。

ディスクだけ空けたい場合は、`models/` フォルダを削除してください（約9GB）。
